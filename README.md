# 🎓 L&D Bot | Sigma Software University

**L&D Bot** — це інтерактивний Telegram-бот, розроблений для автоматизації процесів навчання та розвитку (Learning & Development). Бот допомагає користувачам знаходити актуальні курси, перевіряти свій професійний рівень та отримувати швидку підтримку.

### ⚙️ Функціонал

* 🔄 **Live Parsing:** Актуальні курси та FAQ підтягуються безпосередньо з сайту Sigma Software University у реальному часі.
* 📚 **Каталог курсів:** Зручна навігація по курсах з детальною інформацією (ціна, старт, формат).
* 🧠 **Smart-тестування:** Інтерактивний квіз, що визначає рівень знань користувача (Junior/Middle/Senior) для конкретного курсу.
* ❓ **FAQ Система:** Відповіді на часті запитання (як загальні, так і специфічні для кожного курсу).
* 📞 **Contact Manager:** Форма зворотного зв'язку для швидкого контакту з менеджером.
* 🔔 **Адмін-сповіщення:** Миттєва відправка заявок адміністратору.

### 🛠️ Технологічний стек

Проєкт побудовано на Python із використанням сучасних бібліотек:

* **Core:** Python 3.10+ 🐍
* **Bot Framework:** `aiogram 3.x` (асинхронний) 🤖
* **Web Scraping:** `BeautifulSoup4`, `Requests` 🕸️
* **Config:** `python-dotenv` 🔐
* **Architecture:** Modular (Handlers, Keyboards, States, FSM) 🏗️

### 📂 Структура проєкту

```text
📁 L-D-bot/
├── 📂 handlers/        # Логіка бота (курси, FAQ, загальні команди)
├── 📂 keyboards/       # Клавіатури (inline та reply кнопки)
├── 📂 states/          # Машина станів (FSM) для діалогів
├── 📄 bot.py           # Точка входу (запуск бота)
├── 📄 config.py        # Налаштування та змінні
├── 📄 parser.py        # Скрипт парсингу сайту університету
├── 📄 .env             # Приховані змінні (TOKEN, ADMIN_ID)
└── 📄 requirements.txt # Список залежностей

```

### 🚀 Встановлення та запуск

Слідуйте цим крокам, щоб запустити бота на своєму комп'ютері:

#### 1. Клонування репозиторію

```bash
git clone https://github.com/MykolaYaremov/L-D-bot.git
cd L-D-bot

```

#### 2. Створення віртуального середовища

**Для Windows:**

```bash
python -m venv .venv
.venv\Scripts\activate

```

**Для macOS/Linux:**

```bash
python3 -m venv .venv
source .venv/bin/activate

```

#### 3. Встановлення бібліотек

```bash
pip install -r requirements.txt

```

#### 4. Налаштування середовища (.env)

Створіть файл `.env` у кореневій папці та додайте свої дані:

```env
BOT_TOKEN=ващ_токен_від_BotFather
ADMIN_ID=ваш_telegram_id

```

#### 5. Запуск бота

```bash
python bot.py

```

---

### 🎯 Як користуватися

1. Введіть команду `/start`.
2. Оберіть **"📚 Список наявних курсів"**, щоб переглянути пропозиції.
3. Всередині курсу натисніть **"✅ Чи підійде мені?"**, щоб пройти тестування.
4. Використовуйте **"🛠 Потрібна підтримка"** для зв'язку з менеджером.
